# 唐山教考 2026

唐山工业职业技术大学 2026 年公开选聘（教育类岗位）**笔试备考资料**。

> 笔试：2026-09-27 · 120 分钟 / 100 分 · 教育专业能力测验 + 公共基础知识**合并一张卷** · 全客观题
> 面试：试讲 + 答辩，占总成绩 **60%**（笔试只占 40%）

这不是一套现成的复习资料汇编，是**自己搭的备考系统**：一份能点的考点体系网页、一个 1000 道题的可刷题库，外加出题蓝图和配套工具。

## 怎么用

直接双击 `考点体系.html`，用浏览器打开。不需要装任何东西、不需要联网、不需要起服务。

页面顶部的导航栏切换 14 个分类，键盘 `←` `→` 可以前后翻。刷题区的作答记录和错题本存在浏览器 localStorage 里，关掉再打开还在。

> 手机上看的话，把 HTML 传过去用浏览器打开即可。注意：**localStorage 在 `file://` 下各浏览器行为不一致**，换设备或换浏览器，答题记录不会跟着走。

### 题目格式

```json
{
  "id": "e101",
  "n": 1,
  "module": "教育学",
  "stem": "题干",
  "options": [{"key": "A", "text": "…"}, {"key": "B", "text": "…"},
              {"key": "C", "text": "…"}, {"key": "D", "text": "…"}],
  "answer": "B",
  "explanation": "解析"
}
```

> ⚠️ **当前的题库没有 `type` 字段**，全部隐式视为四选一单选。`n` 是稳定序号，仅用于显示题号。
> 另外 id 没有统一补零——第一批是 `e1`–`e9`，之后是 `e101`、`e201` 这样的三段式。

## 工具

```bash
# 批量加题：把新题分片放进 tools/batches/，加进 PART_FILES，然后
python3 tools/merge.py          # 校验 → 合并进 题库.json → 重新内嵌进 HTML

# 冒烟测试：用 DOM 桩真实跑一遍网页里的内联脚本
node tools/smoke.js             # 99 条断言

# 解析字母重映射探针：选项乱序后，解析里的「故选 B」要跟着换
node tools/remap_probe.js

# 其它
node tools/eyeball.js           # 人工目检：打印原始解析 vs 重映射后的解析
node tools/mkorder.js           # 看一次真实抽题的模块顺序
python3 tools/video/pick.py     # 重新验真 B 站课程链接（需要自备 cookie jar）
python3 tools/video/embed.py    # 把验真后的链接重新嵌入思维导图
```

`merge.py` 写入前会强制校验 id 唯一、`n` 连续、选项齐整，**不通过就不写**。

## 已知局限（重要）

1. **答案未经人工复核。** 1000 题里大部分是按考点生成的，只做了**格式与范围校验，没有逐题核对答案**。刷题时觉得答案别扭，**以教材和法条原文为准，别信题库**。

2. **有时效性的题，考前需要重新确认**，例如：
   - 治安管理处罚法 2025 年修订，2026-01-01 施行
   - 引用《事业单位工作人员处分暂行规定》的题目——该规定已于 2023-09-01 被人社部令第 52 号替代
   - 时政题答案会随新闻变，考前一周重新扫一遍

3. **时政覆盖很薄**（政治与时政模块里时政仅 5 道）。笔试时政通常考考前 3–6 个月，题库覆盖不到那么新，需要另外看新闻。

4. **模考成绩会并进刷题记录**，考完「已做」+120、正确率会变。这是故意的，不想被影响就去刷题区点「清空记录」。

## 下一步：架构改造

现在是一个 56.6 万字符的单文件，其中题库 JSON 占 67%。改一处笔记要把整个文件读进来，成本和风险都高。

`docs/题库架构改造-design.md` 里的方案：

1. 题库进 **SQLite**，结构完整（正确答案、解析、分类、题型、来源）
2. 按导航栏拆成 **15 个内容页 + 首页壳**，每页只装自己那部分
3. **错题本独立成页**
4. 题型从「全单选」扩到 **单选 / 判断 / 多选**，题库扩到 2000 题
