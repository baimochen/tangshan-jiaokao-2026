一 · 教育学基础知识与基本原理

38%

分值最大、考点最散、最需要成体系记忆。以下按考频从高到低排。带 ▸ 的条目在你手上的超格讲义里已覆盖（只有第一、二章）；其余章节不在那份残册内。

教育概述

  • 「教育」一词最早见于《孟子·尽心上》——「得天下英才而教育之」；最早将「教」「育」分开解释的是许慎《说文解字》高频
  • 教育起源四说：神话起源说（最古老）、生物起源说（利托尔诺、沛西·能，第一个正式提出）、心理起源说（孟禄，教育起源于儿童对成人的无意识模仿）、劳动起源说（米丁斯基、凯洛夫，马克思主义观点）高频
  • 教育三要素：教育者（主导）、受教育者（主体）、教育影响（中介）
  • 教育的本质属性：有目的地培养人的社会活动——这是教育区别于其他一切社会活动的根本特征高频
  • 教育的社会属性：永恒性、历史性、相对独立性、继承性、长期性、生产性、民族性
  • 教育的功能：按对象分个体功能 / 社会功能；按性质分正向 / 负向；按呈现形式分显性 / 隐性高频

教育学的产生与发展

  • ▸ 夸美纽斯《大教学论》（1632），近代第一部教育学著作；提出班级授课制、「泛智」教育——「把一切事物教给一切人」高频
  • ▸ 赫尔巴特《普通教育学》（1806），标志规范教育学的建立；提出「教育性教学」原则、四段教学法（明了 / 联想 / 系统 / 方法），以伦理学和心理学为基础——被称为「现代教育学之父」「科学教育学奠基人」高频
  • ▸ 杜威《民主主义与教育》：「教育即生活」「学校即社会」「从做中学」；新三中心——儿童中心、经验中心、活动中心，与赫尔巴特「旧三中心」（教师、教材、课堂）相对高频
  • ▸ 洛克《教育漫话》「白板说」与绅士教育；卢梭《爱弥儿》自然主义教育；裴斯泰洛齐首次提出「教育心理学化」高频
  • ▸ 昆体良《雄辩术原理》（《论演说家的教育》）是西方最早的教育著作，也是世界上第一部研究教学法的书高频
  • ▸ 中国：《学记》是世界最早的一部教育专著，「教学相长」「藏息相辅」「道而弗牵、强而弗抑、开而弗达」均出自此；孔子是最早提出「因材施教」「有教无类」的教育家
  • 马克思主义教育学：凯洛夫《教育学》（世界第一部马克思主义教育学著作）、杨贤江《新教育大纲》（我国第一部马克思主义教育学著作）

教育与人 · 个体身心发展（每年必考）

  • ▸ 身心发展规律及其教育启示：顺序性→循序渐进；阶段性→分阶段施教、不搞一刀切；不平衡性→抓住关键期；互补性→扬长避短、长善救失；个别差异性→因材施教；整体性→促进全面发展高频
  • ▸ 影响发展的四因素及地位：遗传（生理前提、物质基础）、环境（把可能变为现实）、学校教育（起主导作用）、个体主观能动性（决定性因素）——四者地位不能混高频
  • ▸ 内发论：孟子（性善）、弗洛伊德、威尔逊（基因复制）、格赛尔（成熟势力说 / 双生子爬梯实验）、霍尔（「一两的遗传胜过一吨的教育」）、高尔顿（遗传决定论）
  • ▸ 外铄论：荀子（性恶论）、洛克（白板说）、华生（「给我一打健全的婴儿」）、斯金纳高频
  • ▸ 二因素论（辐合论）：施泰伦、吴伟士；多因素相互作用论：皮亚杰

教育与社会

  • ▸ 社会对教育的制约：政治经济制度决定教育的领导权、受教育权、教育目的的性质；生产力决定教育发展的规模与速度、人才培养规格、教学内容与手段；文化影响教育内容与教育传统；人口影响教育规模与结构
  • ▸ 教育的社会功能：政治功能（维系政治稳定、培养政治人才）、经济功能（再生产劳动力与科学知识）、文化功能（传递、选择、创新）、人口功能
  • ▸ 教育与社会关系六种理论：教育独立论（蔡元培）、教育万能论（爱尔维修、康德、洛克）、人力资本理论（舒尔茨，教育是人力资本的核心）、筛选假设理论（迈克尔·史潘斯，教育的作用是筛选与信号）、劳动力市场理论（皮里奥、多林格，二元劳动力市场）、社会化理论（鲍尔斯、金蒂斯）讲义里有，容易被漏

教育目的与教育制度

  • 我国教育目的的根本性质：培养社会主义事业的建设者和接班人；确立的理论依据是马克思主义关于人的全面发展学说高频
  • 教育目的的层次结构：教育目的 → 培养目标 → 教学目标（由一般到特殊）高频
  • 教育目的的价值取向：个人本位论（卢梭、裴斯泰洛齐、福禄贝尔）、社会本位论（涂尔干、赫尔巴特、孔德）、教育无目的论（杜威）
  • 五育并举：德育（灵魂、统帅）、智育（前提和支持）、体育（物质基础）、美育（动力）、劳动技术教育——五育相互联系、不可替代
  • 素质教育的内涵：面向全体学生、促进学生全面发展、促进学生个性发展、以培养创新精神和实践能力为重点
  • 我国学制演变：壬寅学制（1902，首次颁布但未实行）、癸卯学制（1904，首次实行、「中学为体、西学为用」）、壬子癸丑学制（1912，首次规定男女同校）、壬戌学制（1922，「六三三」制，沿用最久）高频
  • 义务教育三大特征：强制性（最本质）、免费性、普及性

课程

  • 课程类型四组：学科课程 / 活动课程；必修课程 / 选修课程；显性课程 / 隐性课程（隐性课程又称潜在课程，属非正式课程）；国家 / 地方 / 校本三级课程高频
  • 课程理论三大流派：学科中心课程论（布鲁纳、施瓦布）、学生中心课程论（杜威）、社会中心课程论（布拉梅尔德）
  • 课程内容三层次：课程计划（教学计划）→ 课程标准（教学大纲）→ 教材
  • 新课改三维目标：知识与技能、过程与方法、情感态度与价值观高频
  • 新课改的课程结构：小学以综合课程为主、初中分科与综合相结合、高中以分科课程为主；从小学至高中设置综合实践活动作为必修课（含信息技术、研究性学习、社区服务与社会实践、劳动与技术教育）
  • 新课改倡导的学习方式：自主、合作、探究

教学（重头）

  • 教学过程四条规律：直接经验与间接经验相统一（间接经验为主）、掌握知识与发展能力相统一、教师主导与学生主体相统一、传授知识与思想教育相统一高频
  • 八大教学原则及其实践对应：启发性（「不愤不启，不悱不发」）、循序渐进（「学不躐等」「不陵节而施」）、因材施教（「深其深，浅其浅」）、直观性、巩固性（「温故而知新」）、量力性（可接受性）、科学性与思想性相统一、理论联系实际——按题干情境反选原则是固定考法高频
  • 教学方法：以语言传递为主（讲授、谈话、讨论、读书指导）、以直观感知为主（演示、参观）、以实际训练为主（练习、实验、实习作业）、以情感陶冶为主（欣赏教学、情境教学）。最基本、运用最广泛的是讲授法高频
  • 教学组织形式：班级授课制（夸美纽斯系统论述，我国最早出现于1862 年京师同文馆）——优点是效率高、利于发挥教师主导作用，缺点是难以兼顾个别差异、不利于培养创新精神；另有个别教学、分组教学、复式教学、现场教学、翻转课堂
  • 教学工作基本环节：备课 → 上课（中心环节） → 作业布置与批改 → 课外辅导 → 学业成绩检查与评定。备课要做好三件事：钻研教材、了解学生、设计教学法；写好三种计划：学期计划、单元计划、课时计划高频
  • 一堂好课的标准：目标明确、内容正确、方法得当、表达清晰、组织严密、气氛热烈
  • 教学评价：按功能分诊断性 / 形成性 / 总结性；按标准分相对评价 / 绝对评价 / 个体内差异评价高频
  • 教学模式：传递—接受（赫尔巴特）、问题—探究（布鲁纳）、自学—辅导、情境—陶冶、示范—模仿

德育

  • 德育过程的基本矛盾：社会通过教育向学生提出的道德要求与学生已有品德水平之间的矛盾高频
  • 德育七大原则：① 疏导原则（循循善诱）② 尊重学生与严格要求学生相结合（马卡连柯「要尽量多地要求一个人，也要尽可能地尊重一个人」）③ 因材施教原则 ④ 知行统一原则 ⑤ 正面教育与纪律约束相结合 ⑥ 依靠积极因素、克服消极因素（长善救失）⑦ 教育影响的一致性与连贯性高频
  • 德育五方法：说服教育法（基本方法）、榜样示范法、实际锻炼法、情感陶冶法、品德评价法
  • 德育途径：思想政治课与其他学科教学（最基本、最经常、最主要的途径）、社会实践活动、课外校外活动、共青团与少先队活动、班主任工作、校园文化高频
  • 德育模式：认知模式（皮亚杰、科尔伯格）、体谅模式（麦克费尔）、社会模仿模式（班杜拉）、价值澄清模式（拉斯）

班主任与班级管理 · 课外校外教育 · 教育研究

  • 班主任工作的中心环节：组织和培养班集体——不是「了解和研究学生」（那是前提和基础，最常见的陷阱选项）高频
  • 班主任工作的内容：了解学生、组织和培养班集体、建立学生档案、个别教育、组织班会活动、协调各种教育影响、操行评定、写好工作计划与总结
  • 班级管理的模式：常规管理、平行管理（马卡连柯）、民主管理、目标管理（德鲁克）高频
  • 班集体的基本特征：明确的共同奋斗目标、健全的组织机构、严格的规章制度、良好的心理氛围
  • 教师劳动的特点：复杂性、创造性、长期性（滞后性）、广延性、示范性、主体性高频
  • 教师的职业素养：道德素养、知识素养、能力素养、心理素养
  • 师生关系：教学上的授受关系、人格上的平等关系、社会道德上的相互促进关系；理想形态为尊师爱生、民主平等、教学相长、心理相容高频
  • 课外校外教育：按内容分科技 / 学科 / 文体 / 社会公益 / 劳动技术活动；特点是自愿性、灵活性、实践性
  • 三结合教育：学校教育、家庭教育、社会教育相结合；学校起主导作用
  • 教育研究基本方法：观察法（最常用）、调查法、实验法、个案法、行动研究法

心理发展与个别差异

  • 皮亚杰认知发展四阶段：感知运动（0–2，获得客体永久性）→ 前运算（2–7，自我中心、思维不可逆）→ 具体运算（7–11，获得守恒、可逆）→ 形式运算（11–16，抽象逻辑、假设演绎）高频

  • 埃里克森人格发展八阶段，重点是青少年期「自我同一性对角色混乱」——这条辅导员面试也常考高频
  • 维果茨基：最近发展区（现有水平与经努力可达到的水平之间的差距）、支架式教学、文化历史发展观

学习理论

  • 行为主义：巴甫洛夫经典性条件反射（狗唾液实验）；斯金纳操作性条件反射——正强化、负强化、惩罚、消退。强化是增加行为频率，惩罚是减少行为频率高频
  • 桑代克试误说与三律：准备律、练习律、效果律（效果律最重要）
  • 班杜拉社会学习理论：观察学习四过程（注意 → 保持 → 再现 → 动机）、替代强化、自我强化高频
  • 布鲁纳认知—结构学习论：发现学习、学科基本结构、编码系统
  • 奥苏贝尔有意义接受学习：实质性的非人为的联系；先行组织者策略；认知内驱力、自我提高内驱力、附属内驱力高频
  • 加涅学习结果五分类：言语信息、智慧技能、认知策略、态度、动作技能；学习层次八阶段
  • 建构主义：知识是建构的而非传授的；学习观强调情境、协作、会话、意义建构；学生观强调已有经验的丰富性与差异性
  • 人本主义：马斯洛、罗杰斯；非指导性教学、学生中心、意义学习

学习动机

  • 动机结构：学习需要（内驱力）+ 学习期待（诱因）；按来源分内部动机 / 外部动机高频
  • 马斯洛需要层次：生理 → 安全 → 归属与爱 → 尊重 → 求知与理解 → 审美 → 自我实现；前四者为缺失性需要，后三者为成长性需要
  • 韦纳归因理论三维度：内外源、稳定性、可控性。把失败归于内部、不稳定、可控（如努力不够）最有利于后续学习高频
  • 班杜拉自我效能感：影响来源为直接经验、替代经验、言语说服、情绪唤醒——直接经验影响最大高频
  • 阿特金森成就动机：力求成功者倾向选择成功率 50% 的任务；避免失败者倾向选择非常容易或非常难的任务
  • 动机理论全景：强化理论、需要层次理论、成就动机理论、成败归因理论、自我效能感理论、自我价值理论（科温顿）

学习迁移 · 学习策略

  • 迁移分类：正迁移 / 负迁移；顺向迁移 / 逆向迁移；水平迁移 / 垂直迁移；一般迁移 / 具体迁移高频
  • 迁移理论：共同要素说（桑代克、伍德沃斯）、概括化理论（贾德，水下打靶实验）、关系转换说（苛勒，小鸡啄米实验）、认知结构迁移理论（奥苏贝尔）、形式训练说（沃尔夫）高频
  • 促进迁移的教学：精选教材、合理编排教学内容、合理安排教学程序、教授学习策略
  • 学习策略三分类：认知策略（复述、精细加工、组织）、元认知策略（计划、监控、调节）、资源管理策略（时间、环境、努力、学业求助）高频

知识、技能与问题解决

  • 知识分类：陈述性知识（是什么，可用言语表述）与程序性知识（怎么做，操作性）高频
  • 知识学习过程：知识的获得（直观、概括）→ 知识的保持（艾宾浩斯遗忘曲线，先快后慢，故复习要及时）→ 知识的应用高频
  • 记忆三存储模型：感觉记忆 → 短时记忆（容量 7±2 组块）→ 长时记忆
  • 技能形成：操作技能四阶段——操作定向、操作模仿、操作整合、操作熟练；心智技能三阶段——原型定向、原型操作、原型内化高频
  • 问题解决四阶段：发现问题（首要）→ 理解问题 → 提出假设 → 检验假设；影响因素含功能固着、定势、原型启发
  • 创造性思维三特征：流畅性、变通性（灵活性）、独创性；创造性思维的核心是发散思维高频

态度品德 · 心理健康 · 教学测量

  • 态度与品德形成三阶段：依从 → 认同 → 内化高频
  • 品德的心理结构：道德认识（核心与基础）、道德情感、道德意志、道德行为（衡量品德的重要标志）高频
  • 心理健康的标准与常见心理问题：焦虑、抑郁、恐惧、强迫、网络成瘾
  • 心理辅导方法：行为改变法（强化、代币、系统脱敏、厌恶疗法）、认知改变法（理性情绪疗法——艾里斯 ABC 理论）、精神分析法、来访者中心疗法（罗杰斯）高频
  • 教学测量四指标：信度（稳定性、可靠性）、效度（准确性、有效性——最重要）、难度、区分度

二之补 · 教育心理学易漏考点

补充

教育心理学里有几个成体系的小块，上面按主线讲了，这里补齐细节。这些正是选择题爱出的地方——理论名称知道，但一问到具体主张就分不清。

学习动机的六个理论（人—理论—主张三方对应）

  • 强化理论（行为主义）——动机是外部强化的结果，与学习本身无关高频
  • 需要层次理论——马斯洛。七层次：生理、安全、归属与爱、尊重、求知与理解、审美、自我实现；前四层为缺失性需要（基本需要），后三层为成长性需要。低层次满足后才会追求高层次高频
  • 成就动机理论——阿特金森。力求成功者倾向选择成功率约 50% 的任务；避免失败者倾向选择非常容易或非常难的任务（因为这两种都能避免「因能力不足而失败」的归因）高频
  • 成败归因理论——韦纳。三维度（内外源、稳定性、可控性）。把失败归于努力（内部、不稳定、可控）最有利；归于能力（内部、稳定、不可控）最有害，易导致习得性无助高频
  • 自我效能感理论——班杜拉。四来源中直接经验影响最大。自我效能感影响活动的选择、努力程度、坚持性和情绪状态
  • 自我价值理论——科温顿。学生把「维护自我价值」作为学习动机，据此分为四类：高趋高避（成功定向者）、低趋高避（逃避失败者）、高趋低避（过度努力者）、低趋低避（失败接受者）。核心观点是「能力＝价值」，所以学生宁愿被认为懒惰也不愿被认为笨高频
  • 另有成就目标理论（德韦克）：掌握目标（关注能力提升）与表现目标（关注他人评价）；德韦克的内隐能力观分能力实体观（固定型思维）与能力增长观（成长型思维）

知识的分类与学习过程

  • 知识按表征形式分：陈述性知识（是什么，可用言语表述，如「北京是首都」）与程序性知识（怎么做，操作性，如「如何解一元二次方程」）。程序性知识又分智慧技能与认知策略高频
  • 知识直观的三种方式：实物直观（看真东西）、模象直观（看模型、图片、视频）、言语直观（用语言描述）高频
  • 知识概括：感性概括（直觉的、表面的）与理性概括（本质的、科学的）
  • 遗忘理论：衰退说、干扰说（前摄抑制——先学的干扰后学的；倒摄抑制——后学的干扰先学的）、同化说（奥苏贝尔）、动机说（压抑说）高频
  • 防止遗忘的方法：及时复习、过度学习（150% 为最佳）、分散复习优于集中复习、复习方式多样化、尝试回忆与反复识记结合高频

心理健康与心理辅导（补充）

  • 心理健康的标准：智力正常、情绪稳定乐观、意志健全、人际关系和谐、适应能力强、自我意识正确高频
  • 中学生常见心理问题：焦虑症（考试焦虑最常见）、抑郁症、恐惧症（学校恐惧、社交恐惧）、强迫症（强迫观念与强迫行为）、网络成瘾、厌学高频
  • 考试焦虑的辅导：认知矫正（改变对考试的消极认知）、放松训练、系统脱敏、提高学习效率。考试焦虑与学习效率同样是倒 U 型关系——适度焦虑最有利于发挥高频
  • 行为改变法具体方法：强化法、代币奖励法（用代币兑换奖励）、行为塑造法（逐步接近目标行为）、示范法（观察学习）、系统脱敏法（渐进式放松对抗焦虑）、厌恶疗法（用厌恶刺激消除不良行为）、惩罚法高频
  • 认知改变法：理性情绪疗法（艾里斯，ABC 理论）、认知疗法（贝克）
  • 心理辅导的原则：面向全体学生、预防与发展相结合、尊重与理解学生、学生主体性、个别化对待、整体性发展高频

课堂管理与教学心理（补充）

  • 课堂气氛三种类型：积极的（师生关系融洽、思维活跃）、消极的（学生紧张拘谨、反应迟钝）、对抗的（师生冲突、纪律涣散）高频
  • 课堂纪律的形成三阶段：反抗 → 自我服务 → 集体自律（柯尔伯格式的道德发展在课堂中的体现）高频
  • 课堂问题行为的处置原则：预防为主、及时处理、最小干预、不中断教学。轻微问题用非言语暗示（眼神、走近、停顿）比当众批评更有效高频
  • 布卢姆的掌握学习：只要给予足够的时间和适当的帮助，绝大多数学生都能达到掌握水平；配套教育目标分类学——认知领域（知识、领会、应用、分析、综合、评价）、情感领域、动作技能领域高频
  • 教学设计的四个基本要素：教学目标、教学内容、教学策略与媒体、教学评价

三 · 教育法律法规

12%

内容少、考点集中、性价比最高的模块。一个上午就能拿下。数字考点尤其爱出选择题。

  • 教师权利六项：教育教学权、科学研究与学术交流权、管理学生权（指导评价权）、获取报酬待遇权、民主管理权、进修培训权高频
  • 教师义务六项：遵纪守法、履行教育教学职责、对学生进行思想品德教育、关心爱护全体学生、制止有害行为、提高思想政治觉悟与业务水平
  • 学生权利：受教育权（最基本的权利）、人身权（生命健康权、人身自由权、人格尊严权、隐私权）、财产权、著作权。体罚侵犯的是人身权／人格尊严权；罚站示众侵犯人格尊严权；没收手机不还侵犯财产权高频
  • 核心法律：《教育法》（教育基本法）、《教师法》、《义务教育法》、《未成年人保护法》、《预防未成年人犯罪法》、《职业教育法》高频
  • 义务教育最本质特征：强制性（另有免费性、普及性）；义务教育年限为九年；实施义务教育不收学费、杂费高频
  • 法律责任类型四选一：行政处分（对内部人员，如警告、记过、降级、撤职、开除）、行政处罚（对外部相对人，如罚款、拘留、吊销执照）、民事责任（赔偿损失）、刑事责任（犯罪）。按题干主体与行为反选高频
  • 《未成年人保护法》六大保护：家庭保护、学校保护、社会保护、网络保护、政府保护、司法保护高频
  • 《学生伤害事故处理办法》：学校担责情形（设施不安全、教师体罚、未及时救助等）与免责情形（不可抗力、学生自行上学途中、学生自杀自伤等）
  • 《新时代中小学教师职业行为十项准则》——首条为「坚定政治方向」
  • 数字考点：教师申诉——教育行政部门应在收到申诉的 30 日内作出处理；学生申诉——对处分决定有异议，可在接到决定书之日起 10 日内向学校学生申诉处理委员会提出书面申诉高频

四 · 教师职业理念

10%

俗称「三观」。内容极少，但每年必出，必须背到能默写。

  • 教育观：素质教育内涵——「提素个性创两全」（提高国民素质、促进个性发展、培养创新精神和实践能力、面向全体学生、促进学生全面发展）高频
  • 学生观：以人为本——「两独一发」（学生是发展的人、独特的人、具有独立意义的人）。发展的人意味着用发展的眼光看学生、允许犯错；独特的人意味着因材施教；独立意义的人意味着学生是学习的主体高频
  • 教师观 · 角色转变：从知识传授者转变为学生学习的促进者；从管理者转变为教育教学的研究者；从课程执行者转变为课程的建设者和开发者；从「教书匠」转变为社区型开放教师高频
  • 教师观 · 行为转变：对待师生关系强调尊重、赞赏；对待教学强调帮助、引导；对待自我强调反思；对待其他教育者强调合作高频
  • 新课改教学观四条：从教育者为中心转向学习者为中心；从教会知识转向教会学习；从重结论转向重结论更重过程；从关注学科转向关注人

五 · 教师职业道德规范

10%

  • 《中小学教师职业道德规范（2008 年修订）》六条：「三爱两人一终身」——爱国守法、爱岗敬业、关爱学生、教书育人、为人师表、终身学习高频
  • 师德的灵魂 / 核心：关爱学生；师德的基础：爱国守法；师德的动力：终身学习高频
  • 师德建设的第一标准：思想政治素质
  • 《中小学教师违反职业道德行为处理办法》：处理包括处分（警告、记过、降低岗位等级或撤职、开除）和其他处理（批评教育、诫勉谈话、责令检查、通报批评、取消评奖评优等）
  • 「四有」好老师：有理想信念、有道德情操、有扎实学识、有仁爱之心高频
  • 四个引路人：做学生锤炼品格的引路人、学习知识的引路人、创新思维的引路人、奉献祖国的引路人
  • 四个相统一：教书与育人相统一、言传与身教相统一、潜心问道与关注社会相统一、学术自由与学术规范相统一

六 · 学生与教师

补充

大纲把它并进「教育学基础知识与基本原理」，但河北同类卷单独命题不少。讲义里对应第四章（第 156 页起），你的残册没有这一章。

学生

  • 学生的本质属性：学生是发展中的人、是以学习为主要任务的人、是完整的人、是有差异性的人高频
  • 学生的权利：受教育权（最基本的权利）、人身权、财产权、著作权；义务：遵守法律法规、遵守学生行为规范、努力学习完成学习任务、遵守学校管理制度
  • 学生的年龄特征阶段性：童年期（6–12）、少年期（12–15，身心发展急剧变化、被称为「危险期」「心理断乳期」）、青年初期（15–18）高频

教师

  • 教师的专业素养四方面：道德素养（对待事业、对待学生、对待集体、对待自己）、知识素养（政治理论修养、精深的学科专业知识、广博的科学文化知识、必备的教育科学知识）、能力素养（语言表达、教育教学、组织管理、自我调控与反思）、心理素养
  • 教师专业发展阶段（福勒与布朗）：关注生存 → 关注情境 → 关注学生——新教师最关注的是「生存」问题（学生喜不喜欢我、同事怎么看我）高频
  • 教师专业发展的途径：师范教育、入职培训、在职培训、自我教育（最主要的途径）；波斯纳的成长公式：经验 + 反思 = 成长高频
  • 教师职业倦怠三维度：情绪耗竭（核心）、去个性化、低个人成就感
  • 教师威信：权力威信与信服威信；信服威信是理想形态

师生关系

  • 师生关系的三种表现：教学上——授受关系；人格上——平等关系；社会道德上——相互促进关系高频
  • 师生关系的基本类型（勒温）：专制型（教师独断，学生表面服从、缺乏主动）、民主型（师生共同商定，学生主动性强，最理想）、放任型（教师撒手不管，学生纪律涣散）高频
  • 我国新型师生关系的特点：尊师爱生、民主平等、教学相长、心理相容高频
  • 影响师生关系的因素：教师方面（起主导作用，含教师对学生的态度、领导方式、智慧、人格）、学生方面、环境方面

七 · 新课改专项

补充

第八次基础教育课程改革。河北同类卷考得很密，且考点固定，属于背了就得分的一类。

  • 新课改的六项具体目标：① 课程功能——改变过于注重知识传授的倾向，强调形成积极主动的学习态度；② 课程结构——改变过于强调学科本位的倾向，设置综合课程与综合实践活动；③ 课程内容——改变繁难偏旧和偏重书本知识的倾向，关注学生学习兴趣和经验；④ 课程实施——改变过于强调接受学习、死记硬背的倾向，倡导主动参与、乐于探究、合作交流；⑤ 课程评价——改变过分强调甄别与选拔的功能，发挥评价促进学生发展、教师提高的功能；⑥ 课程管理——改变管理过于集中的状况，实行国家、地方、学校三级课程管理高频
  • 三级课程管理：国家课程（主体）、地方课程、校本课程（学校自主开发，满足学生个性化需求）高频
  • 综合实践活动——从小学至高中设置的必修课，四大指定领域：信息技术教育、研究性学习、社区服务与社会实践、劳动与技术教育高频
  • 新课改倡导的学习方式：自主学习、合作学习、探究学习。自主＝我要学（主动、独立、元认知监控）；合作＝一起学（分工、互助、共同目标）；探究＝我发现（问题性、过程性、开放性）高频
  • 新课改的评价理念：倡导发展性评价与激励性评价；评价主体多元化（教师、学生自评、同伴互评、家长）；评价方式多样化（定性定量结合、成长记录袋）；改变评价过分强调甄别与选拔的功能高频
  • 新课改的理论基础：建构主义学习理论、加德纳的多元智能理论、后现代主义课程观（多尔的后现代课程观强调丰富性、回归性、关联性、严密性）
  • 新课改下教师角色的四大转变（已见「教师职业理念」）：促进者、研究者、建设者与开发者、社区型开放教师

八 · 教育研究方法

补充

分值不高但每年可能出 1–2 道。讲义第十章（第 329 页起）你的残册没有，只能靠这里补。

  • 观察法——教育研究中最基本、最常用的方法。在自然情境下有计划地考察研究对象。优点：真实自然、不干扰对象；缺点：只能观察到表面现象、难以量化、受观察者主观影响高频
  • 调查法——通过问卷、访谈、测验等方式间接搜集资料。分为问卷调查（面广量大、效率高，但回收率与真实性难保证）与访谈调查（深入，但耗时长、易受访谈者影响）高频
  • 实验法——唯一能确定因果关系的方法。必须控制变量，设置实验组与对照组。分为实验室实验与自然实验（教育实验多为自然实验）高频
  • 个案法——对单一对象（一个人、一个班、一所学校）进行深入细致的研究。优点：深入、具体；缺点：样本小、结论难以推广
  • 行动研究法——教师在自己的教育教学实践中，为解决实际问题而进行的研究。特点是实践性、合作性、反思性；步骤：计划 → 行动 → 观察 → 反思（循环往复）。这是中小学教师最常用的研究方式高频
  • 教育叙事研究——以讲故事的方式叙述教育经验，属于质性研究
  • 抽样方法：简单随机抽样、分层抽样、整群抽样、系统抽样
  • 研究报告一般结构：题目 → 摘要 → 引言（问题提出）→ 研究方法 → 研究结果 → 讨论与分析 → 结论与建议 → 参考文献
